At sprint start save issue keys and original points. Record daily remaining,
completed and added/removed scope points with timestamps. Jira history is the
source for actual transitions. Missing observations stay missing.

Done requires acceptance criteria, real build/browser evidence and reviewed,
merged code where code is involved. File existence is not completion.

At sprint review record completed and unfinished work, scope changes and
carryover. Final presentation: two sprint outcomes, burndown, planned versus
completed points, planned/actual Gantt, PR/commit history, routes, screenshots
and known gaps. Story points are relative estimates, not hours or proof of
individual productivity.

When Anuj requests the day's work: inspect Jira and open PRs, review changed
files, build/check relevant pages, record review, merge eligible teammate PRs
and record actual SHAs/statuses. For absent work, record reassignment to Anuj,
implement on Anuj's branch and open Anuj's PR. Another contributor reviews it.
Never claim another person authored or approved work they did not do.
